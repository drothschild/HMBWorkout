# Exercise Images Implementation Plan — Phase 1: Bundled catalog

**Goal:** Ship a trimmed, pinned copy of free-exercise-db inside the app so title matching works offline from first launch.

**Architecture:** A committed Node script fetches `dist/exercises.json` at a pinned commit, trims every entry to the fields matching needs, and writes a **generated TypeScript data module**. A small typed loader module owns the `CatalogEntry` type, the pinned commit, and the image-URL builder. Pure data, no I/O at runtime.

**Tech Stack:** Node 18+ ESM script (`fetch`), TypeScript, Jest (ts-jest, node project).

**Scope:** Phase 1 of 7 from `docs/design-plans/2026-09-10-exercise-images.md`.

**Codebase verified:** 2026-09-10

## Design deviations recorded in this phase (from codebase investigation)

1. **The catalog ships as a generated `.ts` module, not a `.json` file.** (`resolveJsonModule` is in fact on — inherited from `node_modules/expo/tsconfig.base.json` — so a JSON import would type-check.) The reasons are the repo's conventions, not the compiler: no `src/` module imports JSON today, and `jest.config.js`'s `transform` table covers only `.ts` and `.lv`, which is why `src/hevy/__tests__/loadFixture.ts` reads JSON with `fs.readFileSync` rather than importing it. A generated `export const EXERCISE_CATALOG_DATA: ReadonlyArray<CatalogEntry> = [...]` module also carries a provenance header and a type annotation, and works identically under Metro, `tsc`, and ts-jest with no config change. The design's "reproduces the committed JSON byte-for-byte" becomes "reproduces the committed data module byte-for-byte".
2. **Measured figures differ from the design's.** At pinned commit `a859101d633a01c4a1a920d6a8ce41dabba0705f`, `dist/exercises.json` has **876** entries, **3** have no image, so the catalog has **873** entries and the generated module is ~157 KB (the design said ~124 KB; the script prints the exact figure). The script prints the real figures; the design's numbers are superseded by them.

**Step 1: Create the script**

Existing scripts in `scripts/` are `.mjs` with a `#!/usr/bin/env node` shebang (e.g. `scripts/repro-workqueue-timer.mjs`). Follow that.

```js
#!/usr/bin/env node
/**
 * Builds src/state/exerciseCatalogData.ts from yuhonas/free-exercise-db at a
 * PINNED commit, trimmed to the fields exercise-image matching needs (#335).
 *
 *   node scripts/build-exercise-catalog.mjs          # (re)write the data module
 *   node scripts/build-exercise-catalog.mjs --check  # exit 1 if the committed file differs
 *
 * This script is the source of every quantitative claim about the catalog
 * (entry count, dropped entries, byte size) — re-run it rather than copying a
 * number into prose. The commit below must match FREE_EXERCISE_DB_COMMIT in
 * src/state/exerciseCatalog.ts; exerciseCatalog.test.ts enforces that.
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const COMMIT = 'a859101d633a01c4a1a920d6a8ce41dabba0705f';
const SOURCE_URL = `https://raw.githubusercontent.com/yuhonas/free-exercise-db/${COMMIT}/dist/exercises.json`;
const OUT_PATH = join(
  dirname(fileURLToPath(import.meta.url)),
  '..',
  'src',
  'state',
  'exerciseCatalogData.ts'
);

function trimEntry(entry) {
  // Key order is fixed here so the output is byte-stable across runs.
  return {
    id: entry.id,
    name: entry.name,
    category: entry.category,
    equipment: entry.equipment ?? null,
    primaryMuscles: Array.isArray(entry.primaryMuscles) ? entry.primaryMuscles : [],
    image: entry.images[0],
  };
}

function render(entries, sourceCount) {
  return [
    '// pattern: Functional Core',
    '// GENERATED by scripts/build-exercise-catalog.mjs — do not edit by hand.',
    `// Source: yuhonas/free-exercise-db@${COMMIT} dist/exercises.json`,
    `// ${entries.length} of ${sourceCount} entries (entries with no image are dropped).`,
    "import type { CatalogEntry } from './exerciseCatalog';",
    '',
    'export const EXERCISE_CATALOG_DATA: ReadonlyArray<CatalogEntry> = [',
    ...entries.map((entry) => `  ${JSON.stringify(entry)},`),
    '];',
    '',
  ].join('\n');
}

const response = await fetch(SOURCE_URL);
if (!response.ok) {
  console.error(`fetch failed: HTTP ${response.status} for ${SOURCE_URL}`);
  process.exit(1);
}
const source = await response.json();
const entries = source
  .filter((entry) => Array.isArray(entry.images) && entry.images.length > 0)
  .map(trimEntry);
const text = render(entries, source.length);

if (process.argv.includes('--check')) {
  const committed = readFileSync(OUT_PATH, 'utf8');
  if (committed !== text) {
    console.error('exerciseCatalogData.ts differs from a fresh build — re-run without --check');
    process.exit(1);
  }
  console.log(`OK: committed catalog matches a fresh build (${entries.length} entries)`);
} else {
  writeFileSync(OUT_PATH, text);
  console.log(
    `wrote ${OUT_PATH}: ${entries.length} of ${source.length} entries, ` +
      `${Buffer.byteLength(text, 'utf8')} bytes`
  );
}
```

```ts
// pattern: Functional Core
/**
 * The bundled free-exercise-db catalog (#335). The data itself is generated —
 * see scripts/build-exercise-catalog.mjs — and pinned to one upstream commit so
 * image URLs never move under an already-resolved exercise.
 */
import { EXERCISE_CATALOG_DATA } from './exerciseCatalogData';

export type CatalogEntry = {
  /** Upstream id, e.g. 'Barbell_Squat'. Unique across the catalog. */
  readonly id: string;
  /** Display name, e.g. 'Barbell Squat'. What title matching runs against. */
  readonly name: string;
  /** 'strength' | 'stretching' | 'cardio' | 'plyometrics' | ... (upstream vocabulary). */
  readonly category: string;
  readonly equipment: string | null;
  readonly primaryMuscles: ReadonlyArray<string>;
  /** First image path relative to the upstream `exercises/` dir, e.g. 'Barbell_Squat/0.jpg'. */
  readonly image: string;
};

/** Must equal COMMIT in scripts/build-exercise-catalog.mjs. */
export const FREE_EXERCISE_DB_COMMIT = 'a859101d633a01c4a1a920d6a8ce41dabba0705f';

export const EXERCISE_CATALOG: ReadonlyArray<CatalogEntry> = EXERCISE_CATALOG_DATA;

/** The raw.githubusercontent.com URL of an entry's first image, at the pinned commit. */
export function catalogImageUrl(entry: Pick<CatalogEntry, 'image'>): string {
  return `https://raw.githubusercontent.com/yuhonas/free-exercise-db/${FREE_EXERCISE_DB_COMMIT}/exercises/${entry.image}`;
}
```
